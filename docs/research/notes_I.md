# I real-time — condensed notes
- Single-writer coordinator (FastAPI/asyncio): owns epoch, archive, validation queue, WS fan-out. Persistent workers never respawned during editing.
- Topology (10C=6P/12T+4E): coordinator 1 (NORMAL); 6 interactive islands (BELOW_NORMAL, perturbed weights per island); 2 exact validators (NORMAL, pull-based); <=4 background NSGA-II (IDLE, pausable). = 12 threads, 4 left for browser/OS. Set NUMBA/OMP/OPENBLAS threads=1 in workers; no parallel=True in workers; SetPriorityClass via ctypes; numba cache=True warm-up before READY.
- Control plane: shared-memory int64 control block (epoch, constraint_rev, mass_rev, weights_rev, run_state, bg_pause, per-worker ack+heartbeat, single writer per slot); per-worker spec queue (source of truth); per-worker result pipe; idle workers block on Event. Worker step <= 10 ms, check epoch between steps (not inside numba), improvements <= every 50 ms; watchdog kills/respawns if no ack in 2 s.
- States: CANDIDATE (ghost UNVERIFIED), VALIDATING, VALIDATED (certificate: layout hash, constraint_rev, geometry hashes, tolerance, validator version), REJECTED (failing pairs -> repair), STALE (constraint change), FINAL (frozen, independent mass props).
- Canonical poses: orientation index + integer-micrometre positions => validated == displayed == exported bit-identical.
- Collision ladder: L0 containment (exact for 24 orientations via per-orientation extents), L1 OBB SAT (disjoint proves), L2 convex hull GJK (disjoint proves), L3 voxels (outer-disjoint proves non-collision; inner-overlap proves collision; else penalty only), L4 exact mesh FCL. VALIDATED only if every pair has sound proof from L0/L1/L2/L4 with eps inflation; Stage 2 + clearance, COM box, insertion. L3 never validates alone.
- Validation queue bounded 32, dedup by hash, priority recomputed at dequeue, drop old constraint_rev / can't-beat-best; 25% slots reserved for non-best Pareto candidates.
- Archive ~2,000 validated layouts with raw objective vectors (~2 MB ESTIMATE); geometry certs mass-independent; mass objectives tagged mass_rev; locks/orientation restrictions filter.
- Edit classes: weights (re-scalarise only); mass Stage 1 (optimality only); mass Stage 2 (COM box hard -> recheck displayed O(1) + archive O(K n), no collision); lock/orientation (filter; user-placed part UNVERIFIED until validated); clearance/stage/harness/connector/geometry -> constraint_rev++, STALE, cancel in-flight, revalidate archive best-first.
- WS envelope JSON {v,type,session,epoch,constraint_rev,mass_rev,weights_rev,applied_client_seq,seq,gen,origin_epoch,status,ts,payload}; ~1.3 KB/layout; meshes via HTTP once, cached by hash. C->S hello, edit.*{client_seq,value,commit}, run.control, ping. S->C state.snapshot, edit.ack, metrics.update, layout.validated, layout.candidate, validation.result, progress, pareto.update, status(IDLE/SEARCHING/CONVERGED/PAUSED/REVALIDATING/ERROR), error, pong.
- Throttle: latest-wins mailbox per type; layouts <= 4 Hz (leading+guaranteed trailing), progress <= 10 Hz, acks/metrics unthrottled; timestamp-based (timer granularity ~16 ms); client applies newest per rAF. Reconnect: backoff 250 ms–5 s; hello -> full snapshot (<100 KB ESTIMATE); resend latest intent deduped by (session, client_seq).
- Sequences: weight drag (send <=20 Hz + commit on pointerup; coordinator epoch++, rescalarise archive, ack, publish archive best; 150 ms trailing debounce then spec to islands, adopt <=10 ms); mass edit (O(1) metrics immediately; archive refresh; Stage 2 INFEASIBLE(COM box) flip + best feasible shown); constraint edit; reconnect; finalise.
- Client display rule: never show VALID with older constraint_rev; scores only when applied_client_seq == last sent else "updating"; validity epoch-independent.
- Origin-referenced accumulators: I_O = sum[I_i + m_i(|x_i|^2 E - x_i x_i^T)], I_com = I_O - M(|C|^2 E - C C^T); O(1) per edit/move; full O(n) recompute at each validation.
- Justification: Liu & Heer 2014 (500 ms latency reduces exploration), Nielsen 0.1 s; MOEA/D; Branke; progressive analytics (Stolper 2014; Fekete & Primet ~10 s).
- MEASURED on this machine (Python 3.10.5 stdlib, spawn, no files): empty spawn+join p50 70 ms max 96; Event ping-pong p50 0.027 ms p99 0.088; RawValue spin p99 < 0.001 ms; Queue 1.3 KB p50 0.063 p99 0.150 ms; Queue 100 KB p50 0.238 p99 0.368; time.sleep(1ms) p50 15.55 ms (3.11+ high-res timers -> re-measure); asyncio.sleep overshoot up to ~16 ms (Proactor).
- Latency ESTIMATE: echo <=16.7 ms p95; mass->COM marker 5–25 ms p95; retarget 150–180 ms; first improved valid 0.3–2 s median (censored if archive near-optimal). Exact validation/layout 1–50 ms UNVERIFIED. Comparable: GRIDS 5 layouts in 2 s (5 elements), 5 in 5 s (12 elements).
- Libraries: numba 0.68.0 BSD win wheels cp312/313/314/314t (2026-09-30); wgpu-py 0.32.0 BSD-2 (deferred); PyOpenCL MIT (deferred, wheels UNVERIFIED); psutil optional.
- GPU deferred: layouts tiny (171 pairs), dispatch overhead > CPU; WGSL no f64; browser WebGPU competes with viewport; ROCm PyTorch excludes RDNA2. Keep batch-shaped kernel API evaluate_batch(B,n); revisit if surrogate eval > 50% wall time at B >= 1e3.
- Tests: stale-drop property test (1,000 seeds, 0 violations), rescalarise argmin == brute force, incremental mass props vs independent <= 1e-12 rel over 1e4 edits, lying-surrogate test, cancellation p99 <= step bound + 1 ms + watchdog, Stage 2 COM-box flip test, Playwright scenarios (ramp, 30 Hz jitter, bursts, WS drop, background tab), backpressure bounded memory.
