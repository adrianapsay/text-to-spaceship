# C2 exact mesh collision — condensed notes
- Exact triangle mesh = final authority. python-fcl BVHModel (OBBRSS) per part built once in local frame (float64), pose via fcl.Transform (no rebuild per orientation). manifold3d Manifold per part: intersection volume, hulls, swept volumes, cover verification, min_gap (UNVERIFIED in 3.5.4 wheel — master bindings only), winding_number (UNVERIFIED).
- Proxy hierarchy (each must CONTAIN part): L0 exact AABB per 24 orientations (+OBB/SAT for tilted parts); L1 convex hull (exact for 9 convex parts: battery, ellipsoid, gas tank, rod, payload, sphere, wheel, hex, wedge); L2 CoACD (preprocess_mode=off, decimate=false, fixed seed) accepted only if volume(part − ∪hulls) <= 1e-9 V AND every vertex winding >= 1, else fall back L1 (L2 keeps PCB notches, L1 would fill them and falsely hit PC/104 rods); L3 exact BVH. C1 voxels/SDF as L2b for penalty fields.
- Clearance = distance threshold (d >= c), never geometric offset (offset only for discretised proxies).
- Validator per pair: AABB gap >= c -> certified; else fcl.collide -> intersect FAILS; nested AABB -> containment test (winding number one vertex per component both directions) because FCL is surface-only (soup) and can't see enclosed parts; fcl.distance cross-checked vs manifold min_gap(c+1 mm): disagree > 1 um -> INDETERMINATE; PASS if d >= c − 1 um. Envelope/walls by vertex tests (exact for convex box). Statics (rails, channel, PC/104 rods) as FCL boxes/cylinders.
- FCL distance not penetration depth (negative = in collision; issue #54 wrong nearest points when intersecting) -> use only when separated.
- Stage 1 contact policy proposal: decoders place at target gap g = 5 um (strictly separated, certifiable at 1 um); imported/touching layouts get manifold intersection-volume diagnostic. (B1 proposed contact+2 nm; reconcile.)
- Optimiser: feasible-keeping decoders; drop/advance along −Z by conservative advancement (move by d − c, repeat until < 1 um; 1-Lipschitz distance) on L2 in loop, L3 final. Penalty (free rotation) = Σ over convex-piece pairs max(0, c − d)^2; manifold overlap volume diagnostic/tie-break.
- Stage 2 interlocking: blocking matrix B_u(i,j), u in {+Z, −Z}: part i swept from final pose along u past enclosure end comes within c_ins of j. Prefilters XY-projection AABB disjoint; j entirely on far side. Convex i: hull(V ∪ V + L u). Non-convex i: exact swept volume = P ∪ prisms over triangles with n·u > 0 as prism-triangle soup BVH + vertex-in-prism containment. Fixed L -> cacheable per (part, orientation). Static Z-prismatic frame can't block. Greedy removal (remove any part with no blocker in some direction) is COMPLETE; assembly order = reverse; stall -> INTERLOCKED with stuck set SCCs (rod-through-torus with axes ⟂ Z canonical).
- Theory: Wilson & Latombe blocking graphs; Latombe–Wilson–Cazals. NFP Θ(n^3 m^3), CGAL GPL -> rejected. Literature: Leao 2020 review; Lamas-Fernandez 2023 voxels; Egeblad 2009 translational polyhedra; Cui 2023 FFT with interlock detection (multi-step) — ours stricter.
- Precision: float32 quantisation <= 3.8e-6 mm at |x|<128; double distance ~1e-13 mm; tessellation error >> 1 um (tube bore 9.1 um, torus hole 11.8 um, torus tube 38.5 um) -> mesh authoritative, not analytic primitive.
- ESTIMATES: BVH builds 50–150 ms once; pair distance 0.02–0.5 ms low-poly, 0.2–5 ms 9k–51k tris, <= 10 ms conforming near contact; full validation ~0.15 s typical <= 0.5 s worst (171 pairs + ~9 statics; 40–90 survive L0); interlock 0.05–0.5 s warm, ~2 s first blob sweep; L2 penalty 0.5–9 ms/eval -> 1k–20k evals/s on 12 procs (150–250 convex pieces; python-fcl overhead 10–30 us/call); manifold intersection 0.1–1 ms low-poly, 5–50 ms high; memory ~25 MB. Published: gDist 54x over PQP at 0.38 ms on 7.5M-tri meshes -> ~20 ms CPU (derived).
- Libraries: python-fcl 0.7.0.11 BSD; manifold3d 3.5.4 Apache-2.0; coacd 1.0.14 MIT cp39-abi3 win; trimesh MIT; libigl 2.6.3 MPL-2.0 cp312-abi3 (optional winding oracle); coal excluded (no win wheels); CGAL excluded.
- Tests: T1 box-box gaps {0.5 um,1 um,2 um,10 um,2.2 mm} FCL = min_gap = oracle ±1e-6; g = −1 um collide + intersection vol; T2 containment trap rod coaxial inside capsule (fits: 88.9 >= 80 mm): fcl.collide False (trap documented), validator INVALID via winding, manifold intersection = 6,265.257 mm3; T3 torus/rod coaxial Z distance ~16.99 mm ASSEMBLABLE; axes along X: Stage 1 PASS, Stage 2 INTERLOCKED; T4 facet trap rod in tube bore 5 um analytic gap; T5 U-channel + rod (opening ±Z -> orders; ±Y -> INTERLOCKED); T6 proxy containment vol(part − proxy) <= 1e-9 V + 1e4 random poses zero violations; PCB L2 not hitting rods; T7 cross-impl 1,000 near-contact poses |FCL − min_gap| <= 1 um; T8 exact touching coplanar -> CONTACT in Stage 1; T9 greedy completeness vs exhaustive; T10 timing.
