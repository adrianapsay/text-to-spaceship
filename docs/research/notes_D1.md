# D1 metaheuristics — condensed notes
- Core: memetic BRKGA, 3 keys/part (order, orientation from symmetry-reduced set, placement-rule blend deepest-Z/wall vs toward-axis/COM). Decoder feasible-by-construction (EP/EMS candidates), weight-independent -> slider change = re-rank stored raw objective vectors (us), no re-decode. Deb feasibility rules; overflow measure when part can't be placed.
- Island model: 8 BRKGA islands + 2 refiner islands (LAHC/SA) in persistent spawn pool (Windows; __main__ guard; initializer loads meshes once); 10 workers + validator + main = 12 threads; ticks ~250 ms; ring migration; async islands tolerate P/E cores.
- Seeds: SeedSequence(root).spawn; benchmark mode bit-reproducible (eval budgets, sync migration); interactive mode wall-clock, not bit-reproducible but every displayed layout replayable (chromosome + move log + decoder version + dataset SHA).
- Params start: pop 100–200/island, elite 0.15–0.25, mutants 0.10–0.20, bias 0.6–0.7 (Londe et al.); tune offline with optuna on training instances.
- Memetic LS on elites: key-space moves (reorient, swap, reinsert + Lamarckian writeback) and pose moves (push-to-wall, slack shift off the Z-critical path to improve COM/inertia without increasing L, mirror x/y) with incremental collision and O(1) mass deltas.
- Stage 2: decode order = assembly order; insertion check at placement time -> assemblable by construction; COM box via Deb ordering + COM-repair move.
- Epoch change: rescore pops+archive, display best archived validated layout immediately, reseed islands (top 50% + nearest archive members by weight + mutants); epoch counter polled between generations. Restarts: shake 20–100 stagnant gens, reset 200–500.
- Archive: validated non-dominated set + best per Das–Dennis weight-lattice cell (MOEA/D neighbourhood premise; Branke 1999 memory). Background NSGA-II/III shares encoding/decoder.
- Free rotation: 3 continuous keys + CMA-ES (pycma BSD) refinement, exact-mesh decoder.
- Justification: Gonçalves & Resende 2013 BRKGA+maximal-space equals/outperforms on 858 instances; Parreño 2010 local search; Londe 2023/2025 BRKGA reviews; Peng 2010 portfolios w/ migration; Gomes&Selman 2001; NFL -> must prove by benchmark; satellite module layout GA/PSO with inertia (Zhang, Teng & Shi 2008).
- ESTIMATE: sum OBB volumes ~1,863 cm3; at 75–85% proxy efficiency L ~220–250 mm; uniform block COM_z ~ -60 to -45 mm (inside +-70) — compactness vs COM conflict.
- Cost ESTIMATE: decode 4–10 ms; 100–250 decodes/s/island; ~1,000–2,500/s total; first valid < 0.5 s; weight change to display < 1 ms; spawn cold start 1–3 s (UNVERIFIED) -> persistent pool.
- Benchmark ESTIMATE: 6 variants x 12 instances x 10 seeds = 720 runs ~1.8 h + wall-clock 2x4x10x30 s ~40 min = ~2.5 h (< 3 h cap).
- Libraries: pymoo 0.6.2 Apache-2.0 (cp312/313/314 win wheels, Jun 2026) for NSGA-II/III; pycma BSD (wheel UNVERIFIED); nevergrad MIT (baseline); optuna 5.0.0 MIT (Sep 2026); own BRKGA loop ~150 lines. EXCLUDED: DEAP LGPL, pygmo GPL/LGPL, Platypus GPL, irace GPL.
- Tests: T1 decoder feasibility property test 10k chromosomes; T2 determinism; T3 rerank == re-eval; T4 known optima (8x 50 mm cubes L=100; 4 PCBs L=6.4; symmetric pairs COM~0); T5 one-tick response; T6 stale epochs never displayed; T7 replay; T8 benchmark (variants: BRKGA, LAHC, BRKGA+LS, full hybrid, independent portfolio, multistart constructive; instances 4 presets x {8,12,19} parts; paired Wilcoxon / Mann-Whitney exact, A12 + bootstrap CI, Holm, Friedman, anytime curves, ECDF/IOHprofiler, performance profiles; hypervolume/IGD+). Adoption rule: hybrid ships if A12 >= 0.64 w/ Holm p<0.05 on >= half instances and worse on none.
- Power caveat: 10 seeds -> ~0.39 power for A12 = 0.71 (ESTIMATE) -> report CIs.
- Difficulty 3/5. Rejected: PSO/DE on random keys, CMA-ES for discrete orientations, penalty overlap (keep as later max-compactness mode), pure tabu.
- Limitation: interlocking placements (rod in torus) only reachable if cavity candidate points exist; mesh-aware decoder 10–100x slower (ESTIMATE). Free-threaded CPython 3.14 deps UNVERIFIED.
