# B1 convex collision kernels — condensed notes
- python-fcl 0.7.0.11 BSD-3 (FCL 0.7.0 ambi-robotics fork, libccd 2.1, Eigen 3.3.9 MPL-2.0, octomap 1.9.8), win_amd64 cp312/313/314 wheels (2026-04-08) = primary GJK/EPA. FCL last release 2021-09-09, 208 open issues.
- Exact float64 convex hulls of float32 vertices (cast exact). Convex parts (solidity >= 0.999; 10/19) use H directly. Optional lighter proxy P ⊇ H via support offsets over directions D (decimated hull normals + 26 cube directions) + 1 ulp; HalfspaceIntersection; 26-dir set invariant under 24 rotations -> AABB exact per orientation.
- Orientations: 24 signed permutations via Rotation.create_group('O') exact; drop self-symmetric orientations; free: Rotation.random (Haar) or Hopf grid 72·8^l (72, 576, 4,608) or super-Fibonacci.
- Broadphase: all 171 pairs vectorised AABB inflated by clearance; no tree needed at N=19.
- Narrowphase: walls exact support along ±axes; rails as boxes; pairs fcl.distance(Convex, Convex, enable_nearest_points, enable_signed_distance). Low-poly axis-aligned: cache C-space CB = H_i ⊕ (−R H_j) per pair x relative rotation (<= 171x24 = 4,104 entries): phi(t) = max_k(n_k·t − h_k) exact sign; inside -> exact translational PD; outside lower bound; vertical-line intersection -> exact lowest contact height along −Z (decoder drop primitive). Penalties PD from CB else EPA else min overlap over SAT/D axes (upper bound on PD). Stage 2 insertion: swept convex proxy conv(P ∪ (P + L ẑ)) checked vs installed parts.
- L4 CERTIFICATE only acceptor: candidate normals (GJK witness, exact SAT axes if both hulls <= ~40 edges, set D); gap(n) = min_j n·b_j − max_i n·a_i over ALL vertices float64; s_lb = max gap; accept iff s_lb >= c_req − 1 nm (Stage 1 c_req=0; Stage 2 2.2 mm part-part, 1.2 mm wall/rail). GJK errors -> only false rejects.
- Tolerance policy: CLEAR s >= 0.01 mm; CONTACT |s| < 0.01; OVERLAP s <= −0.01. Accepted layouts true s >= −1 nm. Decoder places at contact + 2 nm.
- Kernel in MILLIMETRES (FCL tolerances absolute: distance_tolerance 1e-6; EPA effectively squared -> ~1e-3 model units = 1 um in mm but 1 mm in m; hard-coded 0.01 unit threshold; python-fcl exposes no tolerance) -> exception to SI internally, confirm with units sweep test.
