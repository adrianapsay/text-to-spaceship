# A2 box implementation — condensed notes
- !! PROCESS ISSUE: A2 also ran in-memory pure-Python prototype incl. BRKGA runs (Python 3.10 via stdin -I; nothing installed/written by agent; harness saved fetched PDFs/background output to its temp). Optimisation experiments pre-approval -> DISCLOSE.
- Own box module ~1–1.5 kLOC NumPy (+optional Numba): EMS space manager (Lai–Chan difference process); G&R BRKGA decoder adapted to strip packing along Z; conservative multi-box proxies; clearance by per-side inflation; obstacles (rails, keep-outs, locked parts); XY-locked PCB-stack macro; geometry-only decoder (cache layouts; mass/weight edits only re-score); fixed-topology LP polish for COM; hand-off to exact validation + compaction.
- Proxy builder: canonical frame = best of authored, PCA, min-OBB by smallest compound proxy (cross natural frame exact 3-bar 28.7 cm3 vs 98.5 min-OBB box); compound <= 6 AABBs from conservative voxel cover merged greedily (exact L 2, U 3, cross 3, notched PCB 2); torus/tube square frame; variant table per rotation (sub-boxes, COM offset, R I R^T; flips kept separately); Stage 2 decorations (3 mm mounting slab under sub-boxes touching mounting face; connector keep-outs) then inflate by delta.
- Space manager: EMS (m x 6) array; vectorised intersection, <= 6 children, G&R pruning, containment/duplicate test on children only; statics inserted first; initial EMS cached per constraint set. Clearance: inflate each part by delta = c_pp/2 + t = 1.2 mm per side; walls shrink by max(0, c_pw + t − delta) = 0. Lemma 1: disjoint inflated boxes -> Euclidean clearance >= 2 delta (conservative). [NOTE: this gives 2.4 mm part-part; our accepted interpretation 2.0 + 0.2 = 2.2 part-part, 1.0 + 0.2 = 1.2 part-wall -> delta = 1.1 per side and wall shrink 0.1.]
- Decoder: 3n keys (sequence argsort; rule gene EMS order (z,x,y)/(z,y,x) = BBL/BLB with Z open; orientation gene among variants fitting EMS). Compound parts anchor sub-box/AABB corner at EMS corner + AABB tests. PCB stack rigid macro at 15.24 mm PC/104 pitch, fixed orientation, XY locked rail-centred, lowest feasible Z. COM-aware rule in 1–2 parallel populations: Tchebycheff of top-Z increase, predicted COM error (unplaced mass at target), parallel-axis increments + products.
- Search: pymoo BRKGA (pe 0.10, pm 0.15, rho_e 0.70, 5 populations exchange 2 best every 15 gens; smaller pop for latency) + background NSGA-II on same keys. [pymoo licence conflict — see D2/F.]
- Polishers: closed-form XY rigid shift toward COM target within slack; fixed-topology LP (SciPy HiGHS) keep each pair's separating axis/sign, variables translations, minimise epigraph Tchebycheff of Zmax and ||COM − t||_1 — every LP solution box-feasible (cf. Trivella & Pisinger packing-class; Gomes & Oliveira 2006 LP compaction); inertia trace convex QP; products in fitness only.
- Stage 2 checks: Lemma 2 single-box proxies insertion from +Z in ascending z-min never collides; compound (cavities) -> greedy disassembly ±Z complete O(n^2 k^2); CDS COM box hard (feasible ranks first).
- Incremental: LRU layout cache keyed by quantised keys + constraint version; mass/density/slider edits re-score cached population O(P n); COM marker O(n); version tags drop stale; ruin-and-recreate (Schrimpf) for dragging/locking few parts, write back as chromosome (keys = z-min rank); batched decoding 12-process pool.
- Exact layer: box-feasible => exact-feasible (Lemma 1) -> first decode VALID once FCL confirms at 1 um; exact compaction (−Z slides conservative advancement/bisection + small XY wiggles, each FCL-validated) recovers proxy waste.
- G&R preprint details: 3n genes; Lai–Chan EMS; removing inscribed EMSs most time-consuming, pruning cuts ~60% runtime; elites not re-evaluated; p = 30n, 5 populations, 300 generations; best on 858 instances. EMS keeps cavities (U 52x26, torus/tube bores) vs EP approximates residual space.
