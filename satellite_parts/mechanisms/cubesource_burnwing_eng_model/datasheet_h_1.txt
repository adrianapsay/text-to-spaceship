1. Product Overview 
The Burnwing Eng. Model is designed to 
facilitate the development and testing of 
burnwire release mechanisms.  
Provided as a kit with a development guide. 
The Burnwing can be used as a stand-alone 
thermal knife release mechanism or as a 
convenient power source/driver board for 
the Flight model. 
2. Key Features 
● Configurable USB C Power Delivery 
● Redundant Burn Channels 
● Overcurrent, Overvoltage, Over Temp.  
and ESD Protection 
● Analog Drive Capability (Logic Level Input)  
● Manual Drive Test Switches 
● PicoBlade or Pico-Lock  
Gold Plated 6-pin Connectors 
● Surface Mount or Through-Hole  
Pulse Withstanding Resistors

4. Functional Description 
The Burnwing operates as a thermal knife release mechanism. Dyneema hold down line is 
used to secure a deployable subsystem in place. When ready for release, a trigger signal 
(BurnCTRL1) is sent for 10 seconds causing the (R1) Burn Resistor to heat to a temperature 
>150°C cutting the hold down line. If the first attempt was unsuccessful this can be repeated 
multiple times. Allow 60 seconds between attempts. (BurnCTRL1) can be active for longer 
than 10 seconds if necessary but this may reduce cycle life. The (R2) burn resistor is a 
redundant backup controlled by (BurnCTRL2) which can be used in the event (R1) has 
failed. Using (R1) and (R2) simultaneously is not recommended. Standoffs or spacers should 
be used when mounting to prevent the resistors from shorting against a frame.  
 
**Safety note: After use allow time for the Burnwing resistors to cool before handling.**
