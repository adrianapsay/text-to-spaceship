Product Introduction
Figure 1-1
Exterior View of the WIS210Y Gyroscope
The WIS210Y is a high-performance MEMS gyroscope independently developed by HUAV. It
features a compact size and lightweight design, integrating a triaxial high-performance
MEMS gyroscope internally, and is screened according to aerospace standards.
Prior to shipment, the WIS210Y undergoes precise calibration and full-temperature range
calibration. It has passed tests including thermal vacuum, EMC, magnetic testing, and
ionizing radiation total dose, enabling it to meet the requirements of aerospace applications.
It can reliably output angular rate, temperature, and real-time diagnostic information in the
space environment.

Equipment Installation and Usage
4.1 Coordinate System
The coordinate system of the WIS210Y is configured as shown in the figure
below. With the connector end facing forward, the X-axis points forward, the
Y-axis points left, and the Z-axis points upward.
4.2 Equipment Installation

The WIS210Y gyroscope must be securely and reliably connected to the user's platform. It should be fastened using
bolts, and the rectangular connector must be securely mated.

Hex socket head cap screws (specification: M4x12, 304 Stainless Steel, Grade 8.8) are recommended for mounting the
device. Recommended torque: 2.45 N·m. If washers are required, the recommended washer specification is: M4x7x0.5
(Stainless Steel).
4.3 Data Recording
After correctly connecting the gyroscope and confirming data output upon power-on, click the "Start Recording" function in
the WisView interactive software. The software will generate a text file in the same directory as the application for real-time
data storage.
4.4 Firmware Upgrade
The WisView interactive software includes a firmware
upgrade function for the gyroscope.
Click the "Firmware Upgrade" button in the Tools menu.
Within the upgrade interface, click "Load Firmware" and
select the correct firmware file from the path. Upon completion, click "Upgrade" to initiate the firmware upgrade process.

User Serial Communication Protocol
The default serial port configuration is: Baud rate 115200 bps, 8 data bits, 1 stop bit, and odd parity. Multi-byte transmission byte
order: high byte first, low byte last.
The product can be configured for either Broadcast or Telemetry mode, which requires a restart to take effect. The default output
mode is Telemetry. The output frequency in Broadcast mode is configurable, supporting up to 1000Hz. In Telemetry mode, the
gyroscope's response time does not exceed 2ms. Response time is defined as the interval between the last bit of a sent command
and the first bit of the gyroscope's reply.
