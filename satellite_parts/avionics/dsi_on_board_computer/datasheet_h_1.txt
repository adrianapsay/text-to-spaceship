OBC 
A highly reliable On-Board 
Computer for small- and 
medium-sized satellites 
 
Lead time for Flight Model: 8-10 months 
 
issue 1.0 
The On-Board Computer (OBC) is a highly reliable failure-
tolerant unit acting as the central command, control and data-
handling unit of a satellite. It is implemented in a compact 
housing and contains a redundant set of modules consisting of 
the processor module (CPM), interface module (IFM) and 
power converter module (PCM). The processor system 
includes a fault-tolerant microcontroller with SDRAM 
(512 MiB net) and a combination of MRAM devices for non-
volatile storage (2 MiB Boot MRAM and 32 MiB data MRAM). 
For the CPU, the GR712RC device (Dual-Core LEON3-FT SPARC 
V8 Processor) from Cobham Gaisler is used. 
This high-performance processor contains two CPU cores, on-
chip SRAM (192 KiB) and provides SpaceWire and serial S-band 
transmitter/ receiver interfaces. The interface board employs 
a Microsemi RTAX2000 FPGA, which implements various 
interfaces for the satellite subsystems. An analogue section of 
the interface board allows the acquisition of data from 
multiple temperature sensors. The power converter module 
converts the unregulated satellite primary power input to 
those needed to supply the processor and interface modules. 
The design of the OBC allows simple adaptions to the type and 
number of interfaces to be made.

This OBC is a compact command, control and data-handling unit for small- and medium-sized satellites. Its special architecture, 
which is composed of a GR712 processor and an interface FPGA, allows easy support for commonly-used sub-unit interface types.  
This OBC was developed for the Eu:CROPIS mission (DLR) and has been operating flawlessly in orbit since December 2018.
